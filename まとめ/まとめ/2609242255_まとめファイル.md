## M08-001 G3 Step1〜3 荷重ケース定義と強度計算

- お題目：G3 Step1〜3 荷重ケース定義と強度計算

### (4) 前提条件

### (5) 経緯

#### Step1：入力条件の整理と安全率基準の設定

確定事項ファイルと機器一覧からG3に必要な入力値（質量・寸法・リンク構成・取付方式・梁情報）を一覧化した。機構部品の質量は未確定のため、リンク材（アルミ30×5mm）・アクチュエータ（1kg級）・リニアガイド・ブラケット・ボルト類から概算し5.5kgとした。

安全率の基準値を検討し、天吊り環境・下方に人がいる条件から「静荷重に対して3以上」を前提条件として設定（A09-001）。繰返し回数は年500回程度で疲労寿命の対象外とし、静的安全率で代替する方針とした。

#### Step2：荷重経路の整理と荷重算定

スコットラッセル機構（OA=AB=AC=r、O固定、B水平スライダ、C鉛直出力）の荷重伝達経路を図示した（チャット内のSVG、保管対象外）。

経路は6ステップ：①CSP→C点、②C→リンクCA→A、③A→リンクOA→O、④A→リンクAB→B、⑤O点ブラケット→M6ねじ→梁、⑥B点ガイド→M6ねじ→梁。左右2組で梁への取付点は4箇所。

荷重ケースとして以下を定義した：
- LC1 自重：131.5 N（常時）
- LC3a 手をつく：150 N 任意方向（偶発。依頼主の使用環境ヒアリングで「子供のぶら下がりは不要、手をつく程度」と確認）
- LC3b 地震：水平Kh=0.6（1階設置、建築設備耐震設計指針準拠）×131.5=78.9 N＋鉛直Kv=0.3×131.5=39.4 N
- LC2 動荷重（昇降加減速）：本セッション未算定。Step5で検討

設計用震度（A09-002）と偶発外力（A09-003）を前提条件として起票した。

**初期計算の誤りと訂正：** 当初、アクチュエータ力を含めずに静的釣合いを解き「O点引抜き=2W_side（片側負担の2倍）」と提示した。しかしスコットラッセル機構はアクチュエータの水平力がないと釣り合わない。アクチュエータを含めた正しい解析では：
- O点鉛直 = W_side（片側負担重量そのもの）
- O点水平 = W_side × cotφ（角度依存、収納端で最大305 N）
- B点鉛直 ≈ 0
O点の合力は最大312 N（収納端）で、誤りの値（偶発時845 N）より小さい方向の訂正だった。

#### Step3：強度計算

5つの荷重経路要素を照査した。成果物として K012_強度計算.md（2609242246_K012_強度計算.md、6210バイト）を作成し引き渡した。以下は照査の要点。

**❶ M6ねじ→梁（O点）**
日本建築学会「木質構造設計規準」の許容引抜耐力式（安全率≈3組込み済み）を使用。梁材はSPF系集成材（基準比重r0=0.32、J3グループ保守側）。M6×50mm、有効ねじ込み深さ45mm。

取付方式について、底面付け（引抜き）と側面付け（せん断）の2方式で比較：
- 方式A（底面・引抜き）：長期683 N/本、短期1,241 N/本
- 方式B/C（側面・せん断）：長期2,227 N/本、短期4,049 N/本
せん断は引抜きの約3.3倍の耐力。いずれも全荷重ケースで安全率≧3をクリア。

取付方式は3候補を残し未確定：
- **方式A 底面直付け**：ブラケットを梁下面に直接ねじ止め。施工は楽だがねじが引抜きで抵抗する最弱モード
- **方式B U字ブラケット**：梁を挟み込み両側面にねじ。せん断で抵抗。ねじ1本が抜けても挟持で脱落防止になり故障モード多重化にも有利
- **方式C アルミフレーム＋アングルブラケット**：梁側面にアングルブラケット（S3060ステンレスキット等）でアルミフレーム（SF2-30×30等）を固定し、T溝で機構を取り付け。せん断で抵抗。メリットは①位置調整が自由（T溝でスライド可能）、②汎用品で組める（専用ブラケットの製作不要）、③梁下面に穴を開けない、④ブラケット複数個で冗長性確保しやすい。依頼主から商品画像とともに提案された方式

**❷ B点ガイドブラケット**：鉛直反力≈0。水平方向のアクチュエータ反力305 N（収納端）のみ。余裕7倍以上。

**❸ リンク部材**：30×5mmアルミフラットバー（A6063-T5、耐力215 MPa）想定。最大312 N → 応力2.1 MPa。安全率103。

**❹ ピンせん断**：M6鋼ピン。最大312 N → せん断応力11.0 MPa。安全率21。

**❺ ブラケット曲げ**：SUS304 30×5mm想定。合力312 N × 腕30mm = 9,360 N·mm → 曲げ応力74.9 MPa。安全率3。全項目中で最も制約に近い。ブラケット2個並べまたは板厚増で余裕確保可能。

### (6) 棄却した案と理由

- **安全率を3未満に下げる案**：天吊り・人下方環境で妥当な水準を維持するため棄却
- **地震力を安全率に含めて独立荷重ケースとしない案（①イ）**：依頼主が①アを選択（設計用震度を前提条件に入れて正式に計算に含める）

### (7) 結論

G3 Step3の照査により、全荷重経路（❶〜❺）で安全率≧3（A09-001）をクリアした。G3-1の移行条件「全荷重経路の安全率が基準値以上」は計算で示された。ただし❺ブラケット曲げが安全率ちょうど3で最も制約に近い。取付方式（A/B/C）は未確定。G3-2（故障モード一覧）は次セッションで着手する。
