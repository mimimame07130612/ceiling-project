## 1 目的

CSP（センタースピーカー）の使用位置・収納位置・ストロークを定め、次の4点の成立性を計算で示す。

- 干渉①：LPの目からSC映像上端への視線をCSPが遮らないこと
- 干渉②：PJ光路をCSPが遮らないこと（SCに影を落とさないこと）
- 収納時に照明の配光へ干渉しないこと（A00-006）
- x方向の配置と、動作範囲内の障害物

## 2 結論

| チルト角 | 下向き20.93°、昇降中も一定 | A02-002 |
| 使用位置（回転中心の高さ） | h=176.74 | A02-004 |

- 干渉②が使用時の下限を決める。CSPの最下点 h=169.10 がPJ光路上端に接する（クリアランス0）。
- 干渉①は効かない。最下点の位置で、視線は h=150.92 にあり、余裕は18.18。
- 収納時の配光は非干渉。最も厳しい断面で、余裕は17.21。
- x方向の障害物は、次の5件（梁1、梁2、照明、SCケース、カーテン）。このうち実際に接するのは梁2だけで、隙間0。
- LP中心に対する横ずれは27.55。
- 収納時の最上点から天井までの隙間は1.48。CSPの上に機構を置く余地がほとんどなく、G2への申し送り事項とする。

### 3.2 置いた条件

- CSPは剛体の直方体とする。クリアランスは0とし、昇降機構は含めない。
- 回転中心は後面下端とする。チルト角は昇降中も一定とし、昇降は鉛直の平行移動とする。
- 視線と光路は直線とする。
- 映像上端はx方向に水平である。このため、d–h面での判定はxに依存しない。
- 配光の円錐は、光源面 h=270 で器具の外縁から半角59°で広がるものとする。

## 4 導出過程

### 4.1 干渉の境界線（d–h面）

- 映像上端：h = 98.75 + 124.5/2 = 161.0（位置は d=25）
- 干渉②（PJ光路上端）：レンズ（305, 217）と映像上端（25, 161.0）を結ぶ直線。
  h₂(d) = 161.0 + (d − 25) × 56 / 280
- 干渉①（視線）：LPの目（270, 100）と映像上端（25, 161.0）を結ぶ直線。
  h₁(d) = 100 + (270 − d) × 61 / 245
- d=45.5 では h₂=165.10、h₁=155.90 となる。どのdでも h₂ > h₁ なので、干渉②が支配的。
- どちらの線も d が大きくなるほど下限が上がるため、CSPを梁領域の前端 d=45.5 に寄せる（A02-001）。

### 4.2 チルト角と使用位置

- 前面の法線をLPの目に向ける条件と、前面下端が h₂ に接する条件を、同時に満たすまで反復計算した。
- チルト角 θ = 20.93°（A02-002）
- 前面下端：d = 45.5 + 21.4·cosθ = 65.49、h = h₂(65.49) = 169.10
- 回転中心：h = 169.10 + 21.4·sinθ = 176.74（A02-004）
- 前面中心：d=68.52、h=177.04
- 干渉①の確認：h₁(65.49) = 150.92。最下点169.10との差は18.18で、干渉なし。
- 底面の傾きは −tanθ で、光路の傾き +0.2 と逆向き。このため、底面は前面下端以外では光路より上にある。

### 4.3 収納位置とストローク

- 収納位置（回転中心）：h = 245 + 21.4·sinθ = 252.64（A02-003）
- 最上点（後面上端）：h = 252.64 + 17.0·cosθ = 268.52。天井 h=270 までの隙間は1.48。
- ストローク：252.64 − 176.74 = 75.90（A02-005）

### 4.4 収納時の配光

- 配光端の半径：r(h) = (270 − h)·tan59° + 11.4/2
- 前面下端の面（h=245）：r = 47.31。照明 d=130 からの配光端は d=82.69。前面下端 d=65.49 との余裕は17.21。
  - 真値は約17.205で、丸めの境目にある。K001は17.20と表記している。
- 前面上端（d=71.56、h=260.88）：r = 20.88。配光端は d=109.12 で、余裕は37.56。
- x=129.65 の照明は、CSPのx範囲（112.90〜170.00）の中にある。このため、側面の断面（K001）が最も厳しい断面になる（K003）。
- x=220.65, d=130 の照明：CSPの角（170, 65.49）までの距離は82.02。r=47.31 との差で、余裕は34.71。
- d=175・220 の照明：同じ列で d=130 の照明より遠いため、上記の判定に含まれる。

### 4.5 x方向と障害物

- CSPのx範囲：141.45 ± 57.1/2 = 112.90〜170.00
- 映像上端のx範囲：146 ± 221.4/2 = 35.3〜256.7。CSPのx範囲はこの内側にあるため、4.1の2次元判定が全幅に成り立つ（K002）。
- PJ光路の平面上の広がり：d=45.5 で x=43.40〜248.60、d=71.56 で x=53.71〜238.29。CSPの幅はこの内側にある（K003）。
- 障害物5件：
  1. 梁1：隙間は 112.90 − 89.5 = 23.40
  2. 梁2：左面 x=170 に接する。隙間0（A02-001）
  3. 照明：4.4のとおり非干渉
  4. SCケース：d=20.5〜33.9 にあり、CSP（d≧45.5）とは前後で離れている
  5. カーテン：前面 d=14、左面 x=14 にあり、CSPの範囲外
- LP中心に対する横ずれ：169 − 141.45 = 27.55

## 5 適用範囲外

- 昇降機構の寸法を含めた干渉。G2で扱う。
- CSPのx位置を、機構の成立性と音響性能のトレードオフで決め直すこと。U01-001として、G2開始で発火する。
- スクリーン購入後の実寸による再確認。A00-003は仮設定である。
