## 3　計算式

**スコットラッセルの仮想仕事の原理より：**

```
F = W × cot(φ)

cot(φ) = x_B / (h_O − h_C)
x_B    = √( r² − (h_O − h_C)² )
```

- φ：リンク OC が鉛直となす角
- F：B点に要する水平力（アクチュエータ推力）
- x_B：B点の水平位置（O直下を原点）

**速度の関係（B等速時）：**

```
v_C = v_B × cot(φ)     ← C点（CSP）の瞬間速度
v_B_avg = B移動量 / T  ← B点の平均速度
```

**仕事量（重力に抗する分）：**

```
E = W × Ls   [N × m → J]
  = 77.47 N × 0.7664 m = 59.4 J
```

## 8　前提と条件

### 前提（値が変われば結果が変わる入力）

| 項目 | 値 | 備考 |
|---|---|---|
| CSP質量 | 7.9 kgf | 機器一覧.csv。機構自重は含まない |
| C点収納高さ（前面下端） | 245.74 cm | 承認済み・起票待ち（A02-003 改訂値より導出） |
| C点使用高さ（前面下端） | 169.10 cm | A02-004 |
| ストローク | 76.64 cm | 承認済み・起票待ち A02-005 |
| リンク長 | 100 cm | M04-005（2r=100） |
| O点高さ | a' h=260 / a'' h=268 cm | M06-002 |
| 荷重分担（a''） | 前 7.10 / 後 0.80 kgf | M04-005（CSP重心を箱中心と仮定） |
| 動作時間 | 60 s | 必要要件の上限いっぱい |

### 条件（結果の適用範囲を画する条件）

- 静的計算。摩擦・機構自重・安全率を含まない
- B点を等速で送る仮定（加速・減速局面の力は別評価）
- 荷重はC点に集中すると仮定
- 重心はCSP箱の中心（実測値なし）
- 適用骨格：「2r=100・収納位置 A02-003・使用位置 A02-004」の骨格に限る
- 案 c には本計算は適用しない（骨格が異なる）
